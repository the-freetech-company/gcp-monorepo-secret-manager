# Support

Monorepo Secret Manager is volunteer-maintained. Please use the right channel:

| Need | Where |
| --- | --- |
| Bug or unexpected behavior | New issue using the **Bug report** form |
| Feature idea | New issue using the **Feature request** form |
| How do I…? | Read the [README](README.md) and [MIGRATION.md](./MIGRATION.md), then open a question issue |
| Security vulnerability | [SECURITY.md](SECURITY.md) — never a public issue |
| Conduct report | [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

There is no SLA. Maintainers listed in [CODEOWNERS](.github/CODEOWNERS) triage
when they can.

Do not email maintainers for general support unless they published an address
here on purpose.
